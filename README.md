# Link Shortener CLI

Сервис сокращения ссылок с поддержкой лимита переходов и времени жизни.

## Как запустить
1. Убедитесь, что установлен JDK 17 и Maven.
2. Выполните сборку: `mvn clean install`
3. Запустите класс `Main` из IDE.

## Поддерживаемые команды
- `shorten <url> [limit]` - Сократить ссылку (опционально указать лимит переходов)
- `go <shortCode>` - Перейти по ссылке (откроет браузер)
- `list` - Показать все ваши ссылки
- `edit <shortCode> <newLimit>` - Изменить лимит переходов
- `delete <shortCode>` - Удалить ссылку
- `notifications` - Показать уведомления
- `help` - Справка
- `exit` - Выход

## Тестирование
Запуск тестов: `mvn test`
